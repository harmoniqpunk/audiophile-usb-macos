Audiophile USB community driver (EXPERIMENTAL)

An unofficial, open-source (MIT) driver for the M-Audio Audiophile USB (USB ID 0763:2003) on macOS 12 Monterey and later. It is not made or supported by M-Audio / inMusic.

Status: experimental, unsigned, not yet tested on real hardware. It may produce no sound, noise, or glitches. It does not install a kernel extension and does not change any security setting.

This installs:

  • /Library/Audio/Plug-Ins/HAL/AudiophileUSB.driver (Core Audio driver)
  • /Library/Audio/MIDI Drivers/AudiophileUSBMIDI.plugin (MIDI driver)
  • /usr/local/bin/apusb-diag (diagnostics tool)
  • /Library/Application Support/AudiophileUSB (diagnostics + uninstaller)

At the end Core Audio is restarted (sound stops for a second) and a read-only diagnostics report is saved to your Desktop.
